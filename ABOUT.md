
# Интернет-магазин «Чудо-Обувь»

## О проекте

Веб-приложение интернет-магазина обуви, разработанное на Laravel.

## Основные возможности

- Просмотр каталога товаров.
- Поиск и фильтрация товаров.
- Просмотр карточек товаров.
- Добавление товаров в корзину.
- Регистрация и авторизация пользователей.
- Оформление и управление заказами.
- Разделы для управления заказами.

## Используемые технологии

- PHP
- Laravel
- MySQL
- HTML
- CSS
- JavaScript

## Назначение

Проект предназначен для демонстрации работы интернет-магазина и основных возможностей веб-разработки.
